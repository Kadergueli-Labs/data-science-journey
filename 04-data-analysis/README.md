# Data Analysis

## Objective

Learn how to explore, clean, analyze, and visualize datasets to extract meaningful insights and support data-driven decisions.

## Topics

- Data collection and loading
- Data exploration
- Data quality assessment
- Missing-value analysis
- Duplicate detection
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Data visualization
- Identifying patterns and trends
- Communicating findings

## Tools

- Python
- pandas
- NumPy
- Matplotlib
- Jupyter Notebook or Google Colab

## Practice

This directory contains data analysis exercises, exploratory analyses, visualizations, and experiments using public datasets.

## Workflow

1. Understand the dataset.
2. Inspect its structure and quality.
3. Identify missing values, duplicates, and inconsistencies.
4. Clean and transform the data when necessary.
5. Explore patterns and relationships.
6. Visualize important findings.
7. Document conclusions and limitations.

## Progress

New analyses and practical exercises will be added progressively as I develop my data analysis skills.
