# SQL and Databases

## Objective

Learn how to store, retrieve, organize, and analyze structured data using relational databases and SQL.

## Topics

- Database fundamentals
- Tables, rows, and columns
- Primary keys and foreign keys
- SELECT, WHERE, and ORDER BY
- Aggregate functions
- GROUP BY and HAVING
- SQL joins
- Subqueries
- Database design and normalization

## Practice

This directory contains SQL queries, database exercises, and practical examples using structured datasets.
